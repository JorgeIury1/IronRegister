# IronLog — Treino Tracker

Um tracker de academia minimalista, preto e verde, feito com HTML, CSS e JavaScript puro.

## Recursos

- Treinos A, B, C, D, E e F
- Cadastro e edição de exercícios
- Agenda semanal com "Add treino"
- Registro de peso e repetições por série
- Histórico de sessões
- PR (maior peso) por exercício
- Gráfico de evolução de carga
- Volume total (peso × repetições)
- Sequência de dias treinando
- Dados salvos no `localStorage` do navegador
- Responsivo para celular e computador

## Rodar

Abra `index.html` no navegador.

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `app.js`.
3. Vá em **Settings → Pages**.
4. Em Source, selecione **Deploy from a branch**.
5. Selecione `main` e `/root`.
6. Salve.

O GitHub vai gerar o link do site.

## Observação

Os dados desta versão ficam no navegador de cada dispositivo. Se o cache/localStorage for apagado, os registros locais serão apagados. Para sincronizar entre celular e PC, a próxima etapa seria adicionar login + banco de dados.
