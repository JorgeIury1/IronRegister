# ForgeLog

Tracker de treinos minimalista em azul-marinho.

- Criação de treinos personalizados, sem A-F fixos.
- Registro de peso e repetições por série.
- Dashboard com treinos registrados por período, dias ativos e volume médio semanal.
- Progressão com volume semanal total/exercício, frequência mensal (3/12 meses) e frequência por dia da semana.
- Agenda semanal.
- Dados salvos no localStorage do navegador.

Para publicar, use GitHub Pages.
